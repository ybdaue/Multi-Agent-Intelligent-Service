# 开书前设定补充 · Novel Setup

新开一本书时用这个技能：把用户的一句话方向、题材或灵感，逐项确认成一套完整可用的设定。
本技能只负责**确认与补全设定**，不写正文、不逐章创作（那些在 writerSkill）。

## 阶段一：爆款基因确认 + 提示词完善

### 1.1 六问锁定爆款基因（逐一询问，每问给选项）

1. **番茄情绪标签**（决定算法推荐）：打脸爽文 / 极致虐恋 / 爆笑反套路 / 悬疑惊悚 / 治愈甜宠 / 脑洞大开
2. **题材与风格**：悬疑推理 / 现代言情 / 古代言情 / 奇幻玄幻 / 科幻未来 / 武侠仙侠 / 历史架空 / 都市现实
3. **主角设定**：男性主角 / 女性主角 / 双主角 / 群像戏（必要时追问职业身份）
4. **主角核心反差点**：表面摆烂实际卷王 / 社恐被迫打脸 / 被虐后觉醒反杀 / 老实人黑化 / 隐藏大佬装萌新 / 看似废柴实天赋异禀
5. **核心冲突**：生死存亡 / 查明真相 / 爱情阻碍 / 复仇雪恨 / 权力争夺 / 成长突破 / 守护保护
6. **章节数量**：10 / 30 / 50 / 100 / 200 / 自定义

记录为 `情绪标签 / 题材 / 主角 / 反差点 / 核心冲突 / 章节数`。

**怎么问**：一次只问一项，拿到答案再问下一项，不要把几项合在一起、也不要把整份清单列给用户。
每问都给上面的备选值，别让用户从零描述。用户说「你定 / 随便 / 不知道」时，按爆款套路替他拟
一版完整可用的，写出来给他过目，确认了才算定稿。

### 1.2 提示词自动完善

在六问结果基础上，按 `references/prompt-guide.md` 的优先级，把一句话方向补全为完整创作提示词：

- **必须补全**：主角人设 + 金手指（含规则/限制）、等级/力量体系、第一个冲突与爽点。
- **应该补全**：世界观规则、配角框架（至少 1 对手 + 1 盟友）、前三章节奏。
- **可以补全**：名场面、中后期走向、语言风格。

金手指必须有规则与限制，不开无限制挂（见「创作原则」）。
人物反差与关系张力参考 `references/character-building.md`，爽点与套路参考 `references/plot-structures.md`。

### 1.3 大纲规划

用 `templates/outline-template.md` 生成 `00-大纲.md`：含节奏蓝图（每 3 章一个「压-小扬-压-爆」
情绪单元）、章节细纲指令、悬念线追踪表、创作进度看板、章节摘要记录区。如需分多卷，额外生成
卷级章节规划（模板见 `assets/volume-plan-template.md`）。

向用户展示规划摘要并**等待确认**后再进入创作。

## 阶段二：人物 / 情绪曲线 / 黄金开篇

- **人物档案**：`templates/character-template.md` → `01-人物档案.md`。每个主要角色必须有
  「一句话传播标签」（身份+反差点+欲望）与「评论区诱导设计」，规范见 `references/character-building.md`。
- **情绪曲线**：按 `references/emotion-curve.md` 的六大情绪标签节奏模板，规划每 3 章的情绪单元，
  并预留「评论区诱导」节点（两难选择/信息差/误解不解释/配角高光/规则争议）。
- **黄金开篇**：按 `references/golden-opening.md` 生成三个版本（强冲突/强反差/强情绪），
  用书中 10 种验证句式与「避雷针」清单筛选，选定 50 字作为黄金开篇。

## 创作原则

- **强代入感 + 快节奏**：每章有进展，不连续两章以上无爽点/无冲突。
- **情绪过山车**：每 3 章完成一次「压-小扬-压-爆」；章末钩子强度不低于上一章。
- **反派不蠢**：衬托不出主角强；金手指有规则限制，不开无限制挂。
